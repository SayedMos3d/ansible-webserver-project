# Automated Web Server Deployment using Ansible

## 📌 Project Overview

This project automates the deployment and configuration of an Nginx web server using Ansible on Ubuntu Linux.

The playbook installs Nginx, deploys a custom HTML page using a Jinja2 template, and ensures that the web server is running and enabled.

## 🛠️ Technologies Used

- Linux (Ubuntu)
- Ansible
- Nginx
- YAML
- Jinja2
- HTML
- SSH
- Git

## 📂 Project Structure

```text
ansible-webserver-project/
├── ansible.cfg

│   └── site.yml
└── roles/

        ├── tasks/
        │   └── main.yml
        ├── handlers/
        │   └── main.yml
        └── templates/
            └── index.html.j2
```

## ✨ Project Features

- Automated Nginx installation using Ansible.
- Automated deployment of a custom HTML webpage.
- Use of variables and Jinja2 templates.
- Nginx service management.
- Handlers to reload Nginx when the webpage changes.
- Organized project structure using Ansible Roles.
- SSH connection to the managed host.

## 🚀 How to Run

### 1. Install Ansible

Make sure Ansible is installed on your Ubuntu system.

### 2. Configure the Inventory

Update the inventory file with the username and connection details of your target host.

### 3. Run the Playbook

From the project directory, run:

```bash
ansible-playbook playbooks/site.yml --ask-pass --ask-become-pass
```

### 4. Verify the Deployment

Check whether Nginx is running:

```bash
systemctl status nginx
```

Test the webpage:

```bash
curl http://localhost
```

You should see the custom HTML page generated by the Ansible playbook.
